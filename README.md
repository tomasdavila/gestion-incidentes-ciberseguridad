# Sistema de Gestión de Incidentes de Ciberseguridad

Aplicación web desarrollada en **ASP.NET Core MVC** como proyecto académico, orientada a la gestión de incidentes de ciberseguridad mediante una arquitectura basada en el patrón Modelo-Vista-Controlador (MVC).

## Tecnologías utilizadas

- C#
- ASP.NET Core MVC
- HTML
- CSS
- Programación Orientada a Objetos (POO)

## Funcionalidades

- Inicio de sesión de usuarios.
- Gestión de cuentas.
- Gestión de activos.
- Gestión de incidentes.
- Control de acceso según el rol del usuario (Administrador y Operador).
- Validaciones de negocio.
- Uso de sesiones para la autenticación.

## Arquitectura del proyecto

El proyecto está organizado en dos capas principales:

- **Dominio:** contiene la lógica de negocio, entidades y reglas del sistema.
- **Web (MVC):** contiene controladores, modelos y vistas responsables de la interacción con el usuario.

## Objetivo

Este proyecto fue desarrollado con fines académicos para aplicar conceptos de:

- Programación Orientada a Objetos.
- Arquitectura MVC.
- Desarrollo web con ASP.NET Core.
- Diseño de aplicaciones por capas.
